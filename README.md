# 🍽️ BiteBot – AI Recipe Generator

**BiteBot** is an AI-powered recipe generator built using the **MERN stack**, **Tailwind CSS**, and **Google Gemini API**. This web application helps users generate customized recipes based on their dietary preferences, taste profiles, and available ingredients. The project focuses on clean UI and a seamless user experience.

---

## 🌟 Features

- 🤖 AI-generated custom recipes using Google Gemini
- 📋 Ingredient-based recipe generation
- 🧠 Support for dietary filters and flavor profiles
- 💻 Built with MERN stack: MongoDB, Express, React, Node.js
- 🎨 Styled with Tailwind CSS for a modern, responsive interface

---

## 🧰 Tech Stack

- **Frontend:** React.js, Tailwind CSS  
- **Backend:** Node.js, Express.js  
- **Database:** MongoDB  
- **AI Integration:** Google Gemini API
